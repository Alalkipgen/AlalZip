# Manual checks for 0.4.0 (UI refresh, grid view, quick access, share)

1. Launch: indigo gradient toolbar shows "Alal Zip / Internal storage"; storage card shows used-space bar and folder/file counts.
2. Toolbar grid button switches between list and grid; grid tiles show thumbnails (JPG/PNG), video frames with play badge (Android 10+), APK icons, and coloured type badges for PDF/DOC/XLS/PPT/TXT.
3. Menu (☰) → Quick access: Download, DCIM, Pictures, Movies, Music, Documents open directly; breadcrumb bar shows Internal storage › Download; tapping a crumb jumps back.
4. Long-press a file: menu shows Open with…, Add to ZIP…, Share, Copy, Cut, Paste, New folder, Delete, Rename, Copy path, Details. Share opens the system share sheet.
5. Select several files: selection toolbar shows count + total size; Share icon disabled when a folder is selected; Create ZIP / Extract / Delete icons work as before.
6. ⋮ → Sort by… shows Name/Size/Date/Type + Ascending/Descending; "Show hidden files" toggles dot-files; Theme cycles System/Light/Dark.
7. Details dialog shows type + MIME, size, modified, access, path; "Copy path" copies to clipboard.
8. Open a ZIP/RAR: gradient header shows file count and unpacked size; breadcrumb chip shows archive path; files open with installed viewers without extracting the whole archive.
9. Rotate the device: view mode, sort, hidden-files and theme persist; passwords never persist.
10. Launcher icon: white "Alal", zipper teeth with amber slider, "ZIP" on black, centered under circle/rounded masks.
